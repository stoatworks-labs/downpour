# Sources for the built-in passages

All four works are in the public domain in the United States.
Each file here is a body-only excerpt: the Project Gutenberg
header, footer and licence are never included, and `--check`
asserts that no reference to them survives. Regenerate with
`tools/extract_texts.py`.

- **alice.txt** -- Alice's Adventures in Wonderland. Lewis Carroll, 1865. Chapter I, 'Down the Rabbit-Hole'. Project Gutenberg ebook #11, lines 58-276.
- **republic.txt** -- The Republic, Book VII. Plato, c. 375 BC. Translated by Benjamin Jowett, 1871. The allegory of the cave. Project Gutenberg ebook #1497, lines 18770-19100.
- **descartes.txt** -- Discourse on the Method, Part IV. Rene Descartes, 1637. Translated by John Veitch, 1850. Methodical doubt, the dream argument and the cogito. Project Gutenberg ebook #59, lines 850-1089.
- **hamlet.txt** -- Hamlet, Act III Scene I. William Shakespeare, c. 1600. 'To be, or not to be'. Project Gutenberg ebook #1524, lines 2767-3066.
